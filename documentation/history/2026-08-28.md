## Fleet alignment + declarative settings port (Obsidian 1.13)

Part of the fleet-wide plugin review. Three commits, in order:

### Catalog reviewer alignment (A–E)

- Stopped export-ignoring `CHANGELOG.md` and `eslint.config.ts` — the community
  catalog reviewer builds and lints the _git archive_, so the stripped
  changelog failed its build while passing locally, and the missing config made
  it fall back to its own ruleset.
- Replaced the markdown import attribute with a `__PLUGIN_CHANGELOG__` bundler
  define (`scripts/build.ts`) — import attributes are not resolvable on the
  Bun version the reviewer builds with.
- Adopted the template eslint config with `DEFAULT_BRANDS` spread; the old
  config disabled sentence-case, hiding 9 findings. Fixed: `as markdown` →
  `as Markdown` (brand casing is enforced both ways), template-canonical
  lowercase support-links wording, anchored `ignoreRegex` escapes for the
  symbol-prefixed button labels (`⎘ Copy md`, `✓ Copied!` — a leading symbol
  makes the rule read the verb as mid-sentence) and the lowercase
  property-name placeholders.
- Pinned `@types/bun` 1.4.0, added `@types/node` 24.10.1, tsconfig
  `types: ["bun", "node"]`. Template overrides block: 8 high vulnerabilities
  → 0. Toolchain: bun 1.4.0, `test --isolate` + `test:watch`, CI audit step,
  `bun run test` in both workflows, `release.sh` with the unattended flags.

### Declarative settings port (`feat!`, minAppVersion 1.10.0 → 1.13.0)

- `getSettingDefinitions()` replaces `display()`: 3 property-name text
  controls (cleared → default fallback preserved in `setControlValue`), 3
  dropdowns validated against their option sets, 2 toggles, the node-spacing
  slider (bounds validated, no `defaultValue`), follow CTA and support block
  as `render:` rows.
- `updateSettings` is the serialized persist-then-commit write path; the
  `graph-explorer:settings-changed` event now fires strictly AFTER the commit,
  so views never re-read state a failed write rolled back.
- `.setting-item.ge-settings-embed` sits OUTSIDE the stylesheet's `@layer`
  blocks (unlayered app CSS beats layered CSS regardless of specificity).
- `settings-write.spec.ts` (queue, rollback, event ordering, rejections;
  mutation-checked three ways) + `settings-guard.spec.ts`.
