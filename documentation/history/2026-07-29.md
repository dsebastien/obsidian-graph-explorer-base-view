# 2026-07-29

## Obsidian 1.13.1 typings + node spacing as a Bases slider option (closes #2)

Issue #2 reported the plugin still used the pre-1.13 Bases option symbols. The rename to `Bases*Option` / `BasesAllOptions` had already landed (commit a5b9f71, obsidian 1.12.0), so this pass finished the migration against 1.13.1:

- Bumped the `obsidian` devDependency and the `resolutions` pin from `1.12.0` to `1.13.1`. Two new type errors surfaced, both from members 1.13.0 added to base classes: `Plugin.settings?: unknown` and `SettingTab.display()`. Fixed by adding `override` on `GraphExplorerPlugin.settings` and `GraphExplorerSettingTab.display()`. `minAppVersion` stays `1.10.0` — no runtime API newer than 1.10 is used.
- Dropped the `as BasesTextOption` / `as BasesToggleOption` / `as BasesDropdownOption` casts in `graph-explorer-options.ts`. They were a leftover from the old `ViewOption[]` typing; the `BasesAllOptions[]` return type discriminates the literals on `type`, so the casts were only hiding checks.
- Renamed the `GraphExplorerView` constructor param `scrollEl` → `containerEl` to match `BasesViewFactory` in 1.13.

### Node spacing moved into the view config

`BasesSliderOption` exists since 1.10.0, so the old "Bases has no slider type" workaround was wrong. `nodeSpacing` is now a `slider` view option:

- `NODE_SPACING_MIN` / `MAX` / `STEP` and `clampNodeSpacing()` live in `types/graph-types.ts`; the options list, the canvas, the controls slider, the settings tab and settings loading all use them instead of repeating `200` / `5000` / `100`.
- The view reads `config.get('nodeSpacing')` and falls back to the plugin setting (`getNodeSpacing()`); the in-graph spacing slider writes back through `config.set`, so the toolbar option and the canvas slider stay in sync.
- The plugin setting is now labelled "Default node spacing" — like every other setting, it only seeds new views.

New specs: `types/graph-types.spec.ts` (clamping) and `views/graph-explorer/graph-explorer-options.spec.ts` (option types, unique keys, slider bounds, defaults from settings). 99 tests pass.

### Needs manual verification in a vault

Cannot be checked from a build: that the node spacing slider shows up in the Bases view config menu, that dragging the in-graph spacing slider persists across a reload, and that the two stay in sync.
