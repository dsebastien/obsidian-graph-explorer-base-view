# 2026-10-09

## Edge source option (issue #12)

- New per-view dropdown **Draw edges from** (`edgeSource`: `all` | `frontmatter` | `body`) + global default `defaultEdgeSource` (settings tab, `loadSettings`).
- `buildGraphData` takes `edgeSource` (last param, default `all`). `all` reads `resolvedLinks`/`unresolvedLinks` as before. `frontmatter` reads `cache.frontmatterLinks`; `body` reads `cache.links` + `cache.embeds`. Each link is resolved via `getFirstLinkpathDest` after stripping the `#subpath`; misses become frontier candidates.
- Decision: default `all`. Changing the default would silently change every existing graph, and most vaults link mainly from the body.
- Presets do not set `edgeSource`, so applying a preset keeps the user's choice.
